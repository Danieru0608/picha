\# Mi Proyecto de Gestión de Código - HPs



Este repositorio tiene como propósito aprender y demostrar el uso práctico de Git y GitHub en un entorno controlado y profesional.



\## Contenido del Proyecto

\* \*\*hp05, hp06, hp07:\*\* Archivos de texto de prueba para el control de versiones.

\* \*\*Manejo de Ramas:\*\* Ejemplos prácticos de integración y resolución de ramificaciones con Git.



\## Requisitos

\* Tener instalado Git en el equipo local.

\* Una cuenta activa en GitHub.
